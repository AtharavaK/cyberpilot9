# CyberPilot Prototype

CyberPilot is a simulated Agentic AI-based cybersecurity platform designed to autonomously assess authorized AI applications using multiple specialized AI agents. This prototype demonstrates the core workflow and interactions between various AI agents described in the CyberPilot architecture.

## Overview
AI applications introduce unique threats such as prompt injection, data leakage, and insecure APIs. CyberPilot aims to identify these vulnerabilities, evaluate risks, and generate remediation recommendations.

This prototype simulates the following modules:
1. **Authorisation & Reconnaissance**
2. **Security Analysis** (AI Security, API Security, Code Review, Infrastructure)
3. **Risk Scoring & Compliance Mapping**
4. **Recommendation Generation**
5. **Report Creation**

## Running the Application
A standalone executable `cyberpilot.exe` is provided. Run it to see the simulated workflow of the Master Agent coordinating the specialized agents.
